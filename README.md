Project One: Java Services and Unit Testing

Overview

This project was completed for my SNHU Computer Science coursework. It includes three Java services: Contact Service, Task Service, and Appointment Service. Each service was developed to meet specific requirements and tested using JUnit 5 in Eclipse.

Projects

Contact Service

The Contact Service manages contact information, including contact ID, first name, last name, phone number, and address. It checks that information follows the required rules, such as making sure required fields are not empty and the phone number contains exactly 10 digits.

Task Service

The Task Service manages tasks. It supports adding, updating, and deleting tasks while checking that task IDs are valid and unique.

Appointment Service

The Appointment Service manages appointments. It supports adding, updating, and deleting appointments while checking appointment IDs, dates, and descriptions against the requirements.

Testing

I used JUnit 5 to test each service in Eclipse. My tests checked valid information, invalid information, duplicate IDs, missing information, and other situations that could cause errors. I used the test results and code coverage reports to review how much of the code was tested.

What I Learned

This project helped me understand how to write unit tests, check software requirements, find errors, and improve software quality. I also gained practical experience using Java, JUnit 5, and Eclipse.
